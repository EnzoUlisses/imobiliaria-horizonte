# Imobiliária Horizonte

Projeto fictício de imobiliária desenvolvido para fins de estudo em HTML e CSS.

## Tecnologias utilizadas
Fiz uso somente das 2 tecnologias que estou estudando: HTML e CSS.

## Sobre o projeto
Criei um site de imobiliária com listagem de imóveis, páginas individuais de cada imóvel, página de contato com formulário e layout responsivo para mobile e tablet.

## O que aprendi
- Semântica HTML com tags como article, section, figure, dl, address
- Flexbox e Grid para layouts
- Responsividade com media queries
- Organização de arquivos e pastas
- Versionamento com Git e GitHub

## Como rodar localmente
Primeiro clone o repositório, logo depois abra o arquivo index.html no navegador.
